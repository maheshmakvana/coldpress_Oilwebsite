# VerdantPure Oils Frontend

Production-grade marketing site for VerdantPure Oils built with React, Vite, Tailwind CSS, and shadcn/ui.

## Prerequisites
- Node.js 18+
- npm 9+

## Getting started
```bash
npm install
npm run dev
```

The site runs at [http://localhost:5173](http://localhost:5173).

## Build
```bash
npm run build
```

## Preview production build
```bash
npm run preview
```

Environment flags:
- `VITE_ENABLE_POSTHOG` (set to `true` to enable analytics)
- `VITE_POSTHOG_KEY` and `VITE_POSTHOG_HOST` for PostHog configuration
